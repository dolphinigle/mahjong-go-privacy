# Mahjong Go — privacy policy

This repository exists only to serve the privacy policy for the Android game
**Mahjong Go** (`com.mahjonggo.game`) over HTTPS, which Google Play requires of
every app.

The policy is [index.md](index.md), published at
<https://dolphinigle.github.io/mahjong-go-privacy/>.

The game itself is a separate, private repository. Nothing here is part of it.

The short version of the policy, which the app is built to make true: Mahjong Go
collects nothing, transmits nothing, and has no network permission at all.
